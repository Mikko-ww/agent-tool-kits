# 角色设定板

输入是一张完整、清晰的角色全身立绘；输出是一张横向 16:9 设定板。目标为原生 2K，不保证达到。设计要求不依赖具体平台、模型、工具名称或参数名。

## 准备生成内容

1. 只以原始立绘为视觉参考，不使用上一次的设定板。若缺图、无法查看、裁切导致角色不完整，或关键区域模糊到无法辨认角色设计，先请用户提供可用的全身立绘。仅裁去背景留白不影响使用。
2. 从参考图整理一份简短英文特征清单，只记录可见且有辨识度的外形、配色和结构。不对称特征只写能确认的角色自身方位与数量；一侧可见不等于另一侧不存在。不逐视角预判遮挡，不把未知项写成出图要求。
   如需辅助读图，可参考[无风格角色反推规则](references/style-free-reverse-rules.txt)识别可见特征、处理遮挡与不确定信息。该文件不是出图模板：本流程只需英文特征清单，不要求双语输出，也不将反推规则拼入提示词。
3. 读取[英文工作模板](references/design-sheet-prompt.txt)，用这份清单替换唯一槽位 `{REFERENCE_FEATURES}`；无可靠补充时删去槽位和对应的小标题。确认最终提示词全英文、无残留槽位，不额外指定侧面朝向。

## 在当前环境执行

先确认当前环境是否能把**一张实际参考图和完整提示词一起提交**。仅支持文字生图，不满足这个条件。工具可用不等于获准把立绘上传到其他服务。

| 要传达的内容 | 适配方式 |
| --- | --- |
| 唯一参考图 | 按当前工具支持的方式传入，例如附件、图像标识或本地路径。不要仅把文件名写进提示词。 |
| 完整提示词 | 使用工具实际提供的文本输入，不假定字段名称。 |
| 16:9、目标原生 2K | 有对应选项就使用；没有的选项用英文补充到提示词中。提示词不是尺寸保证，以实际输出为准。 |
| 一张完整设定板 | 单次调用，能设置数量时选一张。不拆分生成，不局部重绘后拼回，不自动重试。 |

若没有已获准且能接收参考图的工具，返回已展开的英文提示词、应附的参考图说明及画幅设置，明确标记“未生成”。不要自行更换外部服务。

## 交付与验证

返回生成结果或其可访问位置，核对并报告实际像素尺寸与宽高比。若无法读取尺寸则写“未核实”，不放大、拉伸后声称原生 2K。保留实际使用的完整提示词、非敏感生成设置、结果位置和验收结论；不能保存文件时以交付文本记录。

分别核对两件事：版式和视角是否符合要求；角色设计是否与参考中可见的事实一致。可核对的项目记“符合”或“不符合”。可选元素在参考中确认不存在、输出也没有时，记“不适用”；若输出新增的设计与参考中可见的同一区域明确矛盾，记“不符合”。参考区域被遮挡或证据不足时，记“无法核实”，不把“没看到”当成“不存在”。生成一次即停止；只有用户另行要求时才做重复性测试，重复生成不能验证参考未展示的内容。

## 验收标准

按参考立绘和实际输出核对：

- 横向 16:9。左侧是独立的全身英雄图，可持参考中已有的标志性道具；右侧三视图按 Front / Side / Back 标注，标签与实际朝向一致。
- 三视图为同一中性站姿、正交或平行投影、同尺度和视高，头脚对齐；侧面须是全身严格侧面，不只转头。三视图空手，穿戴装备仍保留。
- 角色身份、比例、服装、配色及配件与参考一致；不对称件按角色自身左右核对数量和附着侧，允许自然遮挡。不把不可见部分的推测当作参考事实。
- 标签清晰，色块与可见配色对应。细节区用于解释全身图中难以辨认的设计，仅放大参考中可确认的细节，不要求固定种类或数量。
- 参考中有完整的关键手持物时，细节区应独立展示全貌，不限摆放方向；参考仅露出局部时，仅展示可确认部分。没有此类物件则不要求展示。
